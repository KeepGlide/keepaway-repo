Engine notes

  • Panes are built only from Box (flex, gap, padding, borderStyle round, backgroundColor, width, height), Text (bold, dimColor), Markdown, Svg (fixed width and height) and Button.
  • Italic exists only through Markdown *…* on the desktop, so each title line is one Markdown string: **11:24** *Release beta.24 and push*.
  • No absolute positioning, no CSS, no inner scroll. Both variants are flex rows of two columns around a spine; nothing overlaps.
  • The line is a 2 px Box column with a background colour, stretched by its row. Each marker is a fixed-size Svg centred in a 20 px column. The row stretch is not yet checked in the engine.
  • The alternating layout depends on the pane width when it renders. The engine has no CSS queries, so the host must pass the width and the build must choose the layout. Not verified.
  • Muted grey maps to dimColor. The pane has no shadow and no gradient. The page frames and cards carry shadows for review only.
  • The terminal surface keeps the flat list; this two-sided design is for the desktop pane only.
